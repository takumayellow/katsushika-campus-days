# 葛飾コミュニティハウス（寮）ジェネレータ

裏エンド「寮でぐーたら」(#41) の舞台。キャンパスの外、水戸街道ぞいの実在の建物。
**外観**（route.fbx に混ぜる）を `blender/kcd_route/dorm.py`、**屋内**（独立した `dorm.fbx`）を
`blender/kcd_route/dorm_interior.py` が組み、`blender/build_dorm.py` が headless で回す。

形の数字（footprint・高さ・階数・玄関の点と方位）は **1 つ残らず
`data/osm/route.json` の `dormitory` から読む**。このリポジトリのどこにも
寮の寸法をベタ書きしない。

> **運営は共立メンテナンス（学生会館ドーミー）で、大学の直営ではない。**
> 見た目にも文言にも大学のブランド（`tus_green` など）を使わないこと。
> ゲーム内のセリフでも「大学の寮」と断定しない。

## 実行

```bash
"/c/Program Files/Blender Foundation/Blender 4.5/blender.exe" \
  -b --python blender/build_dorm.py -- --mode both --preview --preview-dir <どこか>
```

| オプション | 既定 | 意味 |
|---|---|---|
| `--mode` | `both` | `exterior` / `interior` / `both` |
| `--json` | `data/osm/route.json` | 形の出どころ |
| `--out-dir` | `unity/.../Assets/Models/Interiors` | `dorm.fbx` と `dorm.json` の出力先 |
| `--exterior-fbx` | off | 外観を単体 FBX に出す。既定では**出さない**（外観の持ち主は route.fbx） |
| `--preview` / `--preview-dir` | off | `dorm_front` / `dorm_oblique` / `interior_dorm*` を 1280×720 でレンダ |
| `--no-export` | off | FBX も `dorm.json` も書かず数だけ測る。ただし読み戻し検証は飛ぶ |
| `--seed` | `20250923` | 小物のばらつき。同じ種なら三角形数まで再現する |
| `--report` | なし | 測った数値を JSON で書き出す |

所要（RTX 5070 Ti / Blender 4.5.10 LTS）: `--mode both` で 2.8 秒、`--preview` 付きで 17 秒。

**`_summary.json` は書かない。** 既存 9 棟の予算（298,267/300,000）には 1 三角形も足さない。
`dorm.fbx` は独立した予算（上限 30,000）。

## 外観（`dorm.build_exterior`）

形は footprint（route.json）から、割り付けと色は実物の写真と航空写真から拾った（写真そのものは
著作物なのでリポジトリに置かない）。辺の呼び名は `dormitory.entrance.edge_index` を基準にする:
玄関面 = 辺 4（南南東、16.477 m）、東北東面 = その次の辺 5（41.963 m）、残りの 4 辺が裏。

* **閉じた立体**（`add_prism`、上下に蓋）: 1 階の基壇（footprint から 0.45 m 内、z −0.60〜3.80）、
  2 階以上の本体（裏は 0.45 m 内、玄関面・東北東面はバルコニーの奥行き 1.50 m 内、`dorm_cream`）、
  角 F の階段室（玄関面 2.40 × 東北東面 5.00 m、屋上から 1.10 m 立ち上がる。`tile_mauve`）、
  屋上スラブ（厚み 0.30 m、5 階のバルコニーの屋根を兼ねる）。屋内へ素通りしないのはこれらが担保する。
* **玄関面・東北東面のバルコニー**（2〜5 階、住戸幅 2.80 m で隔て板、1 層 18 戸）。
  スラブの白い小口（`dorm_white`, 0.20 m）が各階の横じまになる。2 階の手すりはタイル張りの腰壁
  （`tile_charcoal`）、3〜5 階は型板ガラス（`glass_frosted`）+ 白い笠木。奥に掃き出し窓。
  バルコニーの両端は、面に沿って幅 0.45 m の白い袖壁で閉じる。
* **1 階の玄関面**は E から順に茶色いパネル → 小窓のある凹み → 石張り → 黒い壁 → 風除室 →
  黒い目隠しルーバー（`metal_charcoal`）とつる植物。東北東面の 1 階は、階段室の脇に茶色い付属棟
  （長さ 6.0 m・奥行き 1.5 m の閉じた箱。長さは推定）と自販機、その先は暗い灰色の基壇に厨房の勝手口とガラリ。
* **裏の 4 辺**は白い壁（`facade.add_facade`）。2 階以上は居室ごとに縦長の窓 1 つ（3.0 m 間隔、幅約 1.4 m・腰 0.9 m）。
  北北西面は屋内の奥の階段に当たる区間が縦長のスリット窓、エレベーターの区間が窓の無い壁、残りが廊下の
  突き当たりの窓で、その上の屋上に塔屋（エレベーターの機械と階段の出口）。1 階は 3.2 m 間隔の窓で、
  西南西面の大浴場に当たる区間だけ腰 1.8 m の型板ガラスの高窓。角の近くに竪樋 2 本。
  位置は屋内（`dorm_interior.py`）の階段・エレベーター・大浴場・厨房にそろえてある。
* **屋上**: 裏と東北東面にパラペット（高さ 0.60 m・厚み 0.25 m）。玄関面の上はウッドデッキのテラス（ガラス手すり、
  西端にメッシュフェンス、北端に縦格子の手すり、植栽とベンチ）と階段の出口の塔屋。奥に小さな塔屋と
  空調の室外機 4 台。位置は航空写真から測った。
* 玄関は `kcd_lib/entrances.build_one`（庇・両開き・紺の風除室。#39 の共通寸法なので触らない）。
  銘板は道路際の自立サイン 1 つ（`sign_plate` + `metal_charcoal`）。**大学色は使わない。**
  実物の階段室にある大学名の切り文字も入れていない。
* 実物と違うところ: 扉は route.json の `entrance.point`（辺の中点）に置くので、実物より西に寄る。
  西南西面・北北西面は写真が無く、窓割り・塔屋・竪樋は居室数と屋内の間取りからの推定。

### route.fbx への混ぜ方

外観の持ち主は `route.fbx`（`blender/build_route.py`）で、build_dorm.py は既定で外観の FBX を
書かない。`build_route.py` は `dorm.build_exterior(ground.dorm(data))` の躯体と付属物を
route.fbx に入れる。

* **三角形の上限**。route.fbx 全体で 15,925 / 16,000（`--budget`）。外観だけで上限 8,000
  （`build_dorm.py` の `EXT_BUDGET`）。
* **`check_closed` から外観を外す**。外皮は `facade.add_facade` の窓割りと窓ガラスの板で閉じて
  いない（campus.fbx の 9 棟も同じで、`build_campus.py` はこの検査をしていない）。閉じた立体は上の
  基壇・本体・階段室・屋上スラブで、外観そのものの検査は build_dorm.py（footprint 一致・玄関の向き）が持つ。

Unity 側（`DormStage.BuildEntrance`）は玄関を route.json の `door` / `door_bearing` から置くので、
`door_dorm` / `entrance_dorm` の Empty は要らない。

## 屋内（`dorm_interior.build` / `dorm_interior.make_spec`）

16.0 × 38.0 m、天井 2.70 m。原点は `entrance_dorm` の真下の床、+Y が奥。
既存 9 棟と同じ `kcd_interior` の Ctx / InteriorSpec 契約に乗るので、Unity 側は同じ名前を読めばよい。

1F は共用部だけで、居室は無い（2F 女子 23 室、3–5F 男子 77 室）。
**間取りは推定**（公開された平面図は無い）。公式の記載から取ったのは設備の種類
（オートロック、管理人室、食堂 = カフェラウンジ、キッチン、大浴場、マッサージチェア、エレベーター）。
色と什器の形は館内写真から読んだ（ラウンジの橙の壁紙と黄色いソファ、食堂のこげ茶の卓と白い座面の椅子、
キッチンのこげ茶の扉・白い天板・黒いレンジフード）。部屋の位置と寸法、風除室まわりの細部、
エレベーター前の IC ゲート、階段の位置は推定。

* **寮長**は玄関ホール、管理人カウンターの手前 (2.60, 9.60)。
  Empty は `npc_dorm_1` と **`npc_dorm_head`** の 2 つを同じ位置に出す。
  Unity の `DormStage.NpcEmpty` は `"npc_" + DormRoute.DialogueId` = `npc_dorm_head` を探すが、
  既存 9 棟の契約は連番の `npc_<id>_<n>` なので、両方に応える。
* プレイヤーの出現は `spawn_dorm` (0, 4.6)、外へ戻るのは `exit_dorm` (0, 3.35)。
* `c.furn` の順番は entry → hall → lounge → dining → bath → kitchen → corridor → elevator
  （`furn_dorm_02_hall` / `furn_dorm_03_lounge` は変えない）。
* POI は `poi_dorm_kanrinin`（管理人カウンター）/ `poi_dorm_lounge` / `poi_dorm_shokudo` /
  `poi_dorm_daiyokujo` / `poi_dorm_kitchen` / `poi_dorm_corridor_end`。
  サインは部屋ごとに 1 つで `sign_dorm_1`〜`8`（Unity はここに点光源を吊る）。
* 寮専用の什器は `kcd_route/dorm_interior_props.py`（形だけ。Empty は作らない）。
  足したマテリアルは `wallpaper_orange` / `fabric_yellow` / `floor_carpet_gold` / `door_frosted`
  （`kcd_interior/imats.py` と `InteriorPalette.cs` の両方）。浴室のすりガラスの扉は `door_frosted`
  で不透明にしてある。`glass` で始まる名前は Unity の `MaterialLibrary` が半透明にするうえ、
  `glass_frosted` は外観のバルコニーが使っている（マテリアルは名前で 1 つに決まる）。
* 中廊下の引き戸は `shell.door(..., ang=±pi/2)`。建具の向きは「面の法線 = +Y を ang 回転」なので、
  Y 方向に走る壁に `ang=0` で置くと**引き戸が廊下を横切って立つ**。プレビューで一度やった。
* 間仕切りの天端は `Z_PART = 3.20`、外周壁の天端は `Z_TOP = 4.45`。
  **外周壁は間仕切りより 1.10 m（ジャンプの高さ）以上高くしておくこと。**
  同じ高さだと「天井裏の間仕切りの上に立って外へ出られる」と判定され、
  接合部ごとに 0.20 m の隙間（計 1.800 m）が残る。窓の上端 `Z_WIN_TOP = 2.55` は天井より下。
