# 講義棟2階インターナショナルラウンジの位置調査（#444）

調査日: 2026-11-11。公開資料のみ確認。現地確認と Unity 実機確認は未実施。

## 確認できた事実

| 事実 | 根拠 |
| --- | --- |
| 葛飾キャンパスのインターナショナルラウンジは講義棟2階にある | 東京理科大学「その他の設備・施設」 https://www.tus.ac.jp/tuslife/campus/facility/ |
| 2019年度に利便性向上のため講義棟2階へ移動した | 学校法人東京理科大学「2019年度事業報告書」p.18 https://www.tus.ac.jp/about/data/project/business_plan/file/2019_2.pdf |
| 2026年の大学生活ガイドにも「講義棟2階 インターナショナルラウンジ」とある | 東京理科大学「東京理科大学生活ガイド2026」 https://www.tus.ac.jp/tuslife/foreignstudents/universitylife/guidebook_2026.pdf |

これらの資料は階を示すが、2階のどの区画か、入口がどちらを向くかは示していない。

東京理科大学の[2026年春の葛飾まなび発見フェア案内](https://www.tus.ac.jp/today/archive/2026/20260204_0104.pdf)は、講義棟2階の E201・E202・E203 教室と、講義棟3階の学生ラウンジを示す。ただし、インターナショナルラウンジの2階内の位置や入口は示していない。イベント時の用途を常設の室用途と混同しない。



## 別キャンパスの資料との区別

検索で見つかる東京理科大学の[2019年・野田オープンキャンパスのフロアガイド](https://dept.tus.ac.jp/upfiles/sites/2/A212P486.pdf)にも「講義棟2階インターナショナルラウンジ」とある。ただし資料の冒頭・住所・キャンパスマップは**野田キャンパス**を示し、K205〜K207 などの室番号も野田のもの。葛飾の2階の位置や室番号の根拠には使わない。

## ゲーム内の現状と未確定点

`spec.md` §1-4 は、2階東端の L 字ラウンジに「ラウンジ / Lounge」の看板を置く。§10 は、インターナショナルラウンジがこの L 字ラウンジと同じか、北側の長い室かを未確認としている。この二つのどちらかと決めつけない。現時点では英語名を `International Lounge` に替えたり、室内の造形を追加したりしない。

#423 は内装の色・仕上げ・階ごとの什器を扱う。本 Issue は2階の場所と入口表示だけを扱う。

## 次に確認するもの

1. 講義棟2階の案内板の写真。インターナショナルラウンジの表記と、隣の室番号が読めること。
2. ラウンジ入口の写真。廊下から見た位置、向き、室名表示が分かること。
3. 2階のフロアマップ。公開版が見つかれば URL と確認日を記録する。現地の掲示のみなら撮影可能な範囲で記録する。
4. 室内の家具・仕上げは、本 Issue で実装する必要がある場合に別途許可を得て確認する。写真が無ければ推測で作らない。

写真には撮影者・撮影日時・階・向き・共有可否を付け、人の顔が写らないようにする。第三者の画像そのものは権利確認なしにリポジトリやゲームへ入れない。

## 位置が確定した後

`spec.md` と `photo_index.md` に根拠を追記する。必要であれば2階の入口・案内表示だけを既存の Blender 生成スクリプトと Unity のデータに反映し、生成後の Unity 実機で位置と表記を確認する。
