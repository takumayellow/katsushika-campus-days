# 「温室」と呼んでいる小さな棟が実物で何かを確かめ、中を実物に合わせて作り直す

ラベル: area:blender, area:unity, quality

## 何が問題か

ゲームの温室（`blender/kcd_interior/plan_greenhouse.py`）は、ありがちなガラスの温室として作られている。

- 中身: 白い金属の枠の切妻屋根に全面ガラス。天井は 3.30 m、棟はそこから +0.85 m、床はコンクリート。育苗台 2 台、中央の苗トレー、床置きの鉢 5 つ、散水の配管、実験用の流し、閉じた道具棚（#45 の修正）、植物育成灯がある。
- 大きさ: 外形は約 7.5×10.7 m、三角形は 4,128 個。

ところが、この棟が温室だという根拠が見つからない。

- OSM の way 1552188506 に付いているタグは `building=yes` だけで、用途は書かれていない。高さ 3.4 m は PLATEAU の値。
- 「温室」という名前は `tools/osm_extract.py` の 105〜112 行目で決め打ちされている。この決め打ちは足場のコミット e4a4180 で入ったもので、出典は書かれていない。
- 大学の公式ページ、2024 年のオープンキャンパスのフロアマップ、ほかの Web の情報にも、葛飾キャンパスの温室は出てこない。理科大の薬用植物園は野田キャンパスにある。
- 空中写真（地理院のオルソ）では、小さな長方形の棟で、屋根は淡い灰色に見える。ガラスかどうかは判別できない。

建物が何かわからないまま、中身・外観（`build_greenhouse`: 白枠の切妻ガラス、壁高 2.0 m）・クエスト `q_sq_greenhouse`「温室の水やり当番」が作られている。屋内の棟の高さ（3.30 + 0.85 = 4.15 m）も、PLATEAU の建物高 3.4 m を超えている。

## やること

### 1. 調べる（まず何の建物かを確かめる。そのうえで写真をできるだけ多く集める）

- **正体を確かめる**。次のどれかで「何の建物か」の裏を取る。
  - 敷地外の歩道からの現地写真（外壁がガラスか、看板・表示があるか）。
  - 大学（管財・施設の窓口）への問い合わせ。
  - 植物を扱う研究室のページ。葛飾には生命システム工学科の高橋研（https://sites.google.com/view/tus-takahashi-lab/home ）や有村研がある。
  - 地図サービスの写真・ストリートビュー。
- **温室だった場合**: 外観（屋根の形・枠の色・ガラスか波板か）、中（棚・鉢・通路・換気扇・遮光幕・流し・育成灯）、入口の位置（#108）を写真で押さえる。
- **温室でなかった場合**（倉庫・機械室・ボンベ庫など）: 何の建物か、中に入れる建物か、外から見える特徴を記録する。
- **調べる先**:
  - 大学の公式ページ（キャンパスマップ・施設案内）。
  - 設計者（日建設計）の作品ページ。
  - 研究室のページ・論文の実験方法の節（「葛飾キャンパスの温室で栽培」のような記述）。
  - 学生のブログ・SNS、Wikimedia Commons。
- **図面**: `docs/ref/nikken_07.jpg`（配置図兼 1 階平面図 1:2000）で、この位置の棟に名前が書かれていないか見る。
- **写る範囲の記録**: 写真ごとに、どの面のどの向きか、読み取れる寸法、素材と色を書き出す。

### 2. 仕様にまとめる

- この棟が何かと、その根拠（写真・問い合わせの回答・研究室のページ）。
- 温室なら、間取り（通路・棚の並び・入口）、屋根と壁の素材、軒と棟の高さ（PLATEAU の 3.4 m と合わせる）、設備。
- 温室でないなら、中に入れるようにするかを決める。入れないなら、屋内を外すか、別の実在の場所に温室の役を移すかを決める（ユーザーに決めてもらう点）。
- クエスト `q_sq_greenhouse` の文言（「第2実験棟の東の切妻のガラス温室」）を実物に合わせる。

### 3. 作り直す

- **生成側**（`plan_greenhouse.py`、`kcd_lib/buildings.py` の `build_greenhouse`、`tools/osm_extract.py` の決め打ち、要る家具・素材）は、屋内の生成を受け持つ別セッション（dev/interior）が、この Issue の仕様に沿って作る。
- **ゲーム側**は main のセッションがやる。
  - `InteriorStage.cs`・SceneBuilder への組み込み。
  - 入口とゾーン `Zone_poi_greenhouse_*` の置き直し。入口の位置は #108 と合わせる。
  - クエスト `q_sq_greenhouse` と報酬 `c_greenhouse_sprout` の扱い。温室でなかった場合の置き換えもここでやる。
  - 実プレイでの確認。

## 受け入れ条件

- この棟が何かが、出典つきで Issue に書かれている。
- 温室なら、外観と中の主な場所について、実物の写真（またはその出典の URL）とゲームの同じ向きの画面を並べた比較が Issue にある。温室でないなら、名前・外観・クエストが実物に合わせて直されている。
- 棟の高さと大きさが PLATEAU の値（高さ 3.4 m、約 7.5×10.7 m）と矛盾しない。
- 壁の抜け（#45）や、落ちて戻れない所が無い。EditMode・PlayMode のテストが通る。

## 写真の扱い

- 著作権のある写真はリポジトリに入れない。出典の URL と、そこから読み取った寸法・色・配置のメモだけを `docs/ref/interiors/greenhouse/` に残す。
- Commons など自由なライセンスの写真や、自分で撮った写真は、帰属表示つきで入れてよい。

## 調べてわかったこと（2026-09-24 時点）

- **中の写真は 1 枚も見つからなかった。** 外観の地上写真も見つからなかった。
- `data/osm/campus.json` の `greenhouse`: 1 階・高さ 3.4 m・「ガラス張りの温室。」、osm_id 1552188506、bbox は x 105.3..115.7、y 15.5..28.3（原点は緯度 35.771909746153845・経度 139.86296726153847、x = 東、y = 北）。「ガラス張り」の出どころは `osm_extract.py` の決め打ちで、OSM にも PLATEAU にもその情報は無い。
- 空中写真: `origin/dev/assets` の `docs/ref/aerial/crop_roofs_north.jpg`（地理院のオルソ z18 から作ったもの）を拡大した。小さな長方形の屋根で、色は淡い灰色、北の端に白っぽい帯と黒っぽい物がある。まわりは木に囲まれている。ガラス屋根かどうかは、この解像度（約 0.25 m/px）では判別できない。ローカルの保存先は `research/others/misc/greenhouse/greenhouse_gsi_ortho_zoom.jpg`（出典: 国土地理院の写真）。
- 公式のキャンパス案内（https://www.tus.ac.jp/tuslife/campus/katsushika/ ）と施設紹介（https://www.tus.ac.jp/tuslife/campus/facility/ ）に、温室は出てこない。
- 理科大の薬用植物園は野田キャンパスにある（https://www.ps.noda.tus.ac.jp/utility/garden/ ）。葛飾キャンパスのものではない。
- 外観の生成は `kcd_lib/buildings.py` の `build_greenhouse`（白枠の切妻ガラス、壁高 2.0 m）。入口は西の妻面（歩道側、SMALL、`entrances.py`）。
