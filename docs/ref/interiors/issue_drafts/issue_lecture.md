講義棟の中を実物の写真と平面図から作り直す（600 席ホールは図書館へ）

## 何が問題か

ゲームの講義棟の中（`blender/kcd_interior/plan_lecture.py`）は、1F に 3 層吹き抜けの大階段ホール、600 席の大ホール（赤いカーペット・紺の壁・黒い天井・木の舞台）、ホワイエ、中教室とゼミ室 3 室を並べたものになっている。実物とは次の点が違う。

- **600 席の大ホールは講義棟には無い。** 実物の 600 席のホールは図書館の大ホール（3・4 階）で、#110 の範囲になる。`tools/osm_extract.py` の図書館の説明にも「600 席の大ホール（3・4 階）」とある。講義棟でいちばん大きい教室は 270 名（大学の案内）。
- **実物は中廊下型の教室棟。** 各階の中央を東西に廊下が通り、両側に教室が並ぶ。1〜5F で約 50 教室。中央のコアに EV・男女トイレ・小さな吹き抜け・1F から 5F へのエスカレータがある（精密工学会 2023 年春季大会の会場案内の平面図、オープンキャンパス 2024 のフロアマップ）。
- **3 層吹き抜けの大階段ホールは実物に無い。** 東端が半円に張り出していて（オープンキャンパスのフロアマップでは 3F・4F）、3F の東端は半円のラウンジ（飲み物の自販機）になっている。2F の東端もラウンジ（平面図）。3F のラウンジ 3 では昼に弁当を売る。
- **1F の部屋が違う。** 実物の 1F は 101・102（大教室。間に南の入口）、103、104、保健管理センター、中央監視室。東の入口は金町駅側、西の端は学生食堂のある管理棟へつながる。1F に売店（弁当・文具・書籍・白衣）がある。
- **教室の仕上げが違う。** 実物の大教室は、明るい木の縦スリットの壁、緑の黒板と青緑のボード、木の固定長机と木のシェル座面（灰色のスチール脚）、濃い灰色のカーペット、白い天井にライン照明と天井吊りのプロジェクター、ゆるい段床。ゲームの赤・紺・黒の劇場の配色とは合わない。

## やること

### 1. 調べる（写真をできるだけ多く集める）

- **集めたもの**（計 6 枚、出典と説明は `docs/ref/interiors/lecture/` に移す）
  - 大教室の写真 1 枚：https://www.tus.ac.jp/tuslife/campus/katsushika/
  - 1F〜5F の平面図と階ごとの使い方 3 ページ：https://2023-03spring.jspe.or.jp/wp/wp-content/uploads/pdf/23-03-kaijo.pdf （p2〜p4）
  - 2F〜5F のフロアマップとキャンパス鳥瞰図 2 枚：東京理科大学 2024 春の葛飾オープンキャンパスのリーフレット（floormap_20240219.pdf）
  - 売店・ラウンジの営業情報：https://www.tus.ac.jp/foodmap/
- **まだ無いもの**：1F のエントランス・中廊下・エスカレータまわり・東端の半円ラウンジ・中教室（30〜100 名）の写真、階高と天井高。102 教室の会場ページ https://eplus.jp/sf/venue/1250053 は取得できなかった（503）。学会・イベントの会場案内、学生のブログ・SNS、Google マップの屋内写真を当たる。
- **写る範囲の記録**：写真ごとに、どの部屋のどの向きか、読み取れる寸法（天井高・廊下幅・机の大きさ・段の高さ）、素材と色を書き出す。

### 2. 仕様にまとめる

- 1F の間取り：中廊下、101〜104・保健管理センター・中央監視室・売店、南と東の入口、西の管理棟への接続、中央コア（EV・トイレ・エスカレータ・小さな吹き抜け）。2F 以上は、階段とエスカレータで上がった先の廊下と東端のラウンジまでを範囲にするかを決める。
- 仕上げ：廊下と教室の床・壁・天井の素材と色、照明の種類と並び。
- 家具：大教室（270 名）と中教室の机・椅子・黒板・教卓・プロジェクター、ラウンジの椅子と自販機。
- 窓の位置と外の見え方。窓の外の近景は #60・#84 と合わせる。

### 3. 作り直す

- **生成側**（`plan_lecture.py` と、教室と廊下に要る家具・素材）は、屋内の生成を受け持つ別セッション（dev/interior）が、この Issue の仕様に沿って作る。600 席ホールの部品は #110 の図書館大ホールへ回す。
- **ゲーム側**（`InteriorStage.cs`・SceneBuilder への組み込み、入口とゾーン `Zone_poi_lecture_*`、`collectibles.json` の `poi_lecture_hall_booth`・`poi_lecture_seminar`・`poi_lecture_atrium` の置き直し、`Mobs/schedule.json` の入口 `lecture`、実プレイでの確認）は main のセッションがやる。

## 受け入れ条件

- 講義棟の主な場所（1F 入口・中廊下・大教室・東端のラウンジ）それぞれについて、実物の写真（またはその出典の URL）とゲームの同じ向きの画面を並べた比較が Issue にある。
- 間取り・天井の高さ・床と壁の色・家具の並びが、仕様に書いた実物の値に合っている。
- 講義棟に 600 席のホールが残っていない。
- 壁の抜け（#45）や、落ちて戻れない所が無い。EditMode・PlayMode のテストが通る。

## 写真の扱い

- 著作権のある写真と図面はリポジトリに入れない。出典の URL と、そこから読み取った寸法・色・配置のメモだけを `docs/ref/interiors/lecture/` に残す。
- Commons など自由なライセンスの写真は、帰属表示つきで入れてよい（今回は見つからなかった）。
