## 0. 座標の決め方（ゲームの外形との対応）

- 座標はすべてローカル座標。原点は entrance_library の真下の床、+Y が奥（建物の中へ）、Z が上、単位は m。
- **入口**（REPO、高）: `entrances.py` の `("library", (-50.0,-24.0), (-1.0,0.0), "inner1", +1, 3.4, STANDARD)`。面 `inner1` は外周から 2.2 m 引っ込んだ 1F のガラス面。扉は W 1.6 / H 2.6 / D 2.0。ローカルでは入口の X = 0、正面のガラス面の外側 Y 4.0、内側 Y 4.3。照合（`door_mismatch`）は内積 < −0.9、面に沿った差 ≤ 0.05 m。`spawn_library` (0, 5.8, 0)、`exit_library` (0, 4.55, 0) は今の値を保つ。
- **外形**（REPO、高）: campus.json の library（levels 5、height 22.0、面積 4,840 m²）。輪郭（ローカル）: (49.3,14.2) (41.1,15.4) (41.3,59.5) (15.6,60.0) (15.9,63.4) (0.9,66.7) (−14.9,63.5) (−14.7,60.6) (−40.9,61.1) (−41.7,4.2) (0.2,4.7) (49.7,4.0)。
  - 右の切欠き X 41.1〜49.7 × Y 15.4〜59.5 は輪郭の外で、何も置かない。
  - 奥は Y ≈ 59.5〜61.1 で、X −14.9〜15.9 だけが Y 63.4〜66.7 まで張り出す。
  - 西の辺は (−41.7, 4.2) から (−40.9, 61.1) へ 0.8 m 傾く。屋内の西の壁は内面 X −41.35 の直線にする（`SecretStoryStage.cs` が 2F の Y 42.3 にこの壁を探すため。§2）。
  - 正面の辺は (−41.7, 4.2)・(0.2, 4.7)・(49.7, 4.0) を結ぶ折れ線で、入口の X 0 では Y 4.7 にある。屋内の正面のガラスは入口の契約（外側 Y 4.0・内側 Y 4.3、`exit_library` Y 4.55、`spawn_library` Y 5.8）に合わせて Y 4.0 の直線にする。このため正面のガラスと Y 4.0〜4.7 の床の縁は輪郭から最大 0.7 m 前に出る（西の壁と同じ扱い）。
- **各階の高さ**（中）: 矩計図（NK08）で 1F〜2F・2F〜3F が 5,000、3F〜4F が 6,000 と読める。断面図（CT05・mt_sec）を「高さ 6 m の本の壁」で割り出した値（2F 約 4.8〜5.0、3F 約 10、ホワイエの天井 13.6〜14.2、4F 15.4〜16.3）とも合う。BLD の値（1F 0 / M1 1.7 / M2 3.3 / 2F 5.0 / 3F 10.0 / ホワイエの天井 14 / 4F 16.0）を採る。
- **向き**（中）: MAP25 の「図書館正面出入口」と SEC3F のテラスはどちらも図の下辺の中央やや左にあり、ゲームの入口の位置（外形の幅の 0.46）と 3 m ほどしか違わない。**図の下 = 入口側（−Y）、図の左 = −X** とした。断面図（mt_sec）は舞台が奥（+Y）、2 階席が入口側。
- **寸法の扱い**: 実物の本体は約 75 × 48 m（SEC3F の柱の間隔を NK08 のスパン 9,000 に当てた推定）で、campus.json の外形（約 91 × 63 m、大屋根・テラス・ピロティを含む）より小さい。**寸法は campus.json の外形を正とし**、図面と写真からは並び順と比率だけを使う。
- **大ホールの位置**（中）: 断面図でホールは図書館の上に載る長さ約 42 m の箱で、ガラスの床とトップライトの帯（NKA、CT02）がその入口側と外周にある。この仕様ではホールの外殻を X −19.5〜16.3（入口の軸の左寄り、外殻の内側の中心 X −1.6）× Y 18.5〜59.9 に置き、舞台の奥の Y 59.9〜63.0 は輪郭の奥の張り出しに収まる X −14.6〜15.5 に絞る（張り出しの外の奥の辺は X −19.5〜−14.9 で Y 約 60.7、X 15.9〜16.3 で Y 約 60.0）。
