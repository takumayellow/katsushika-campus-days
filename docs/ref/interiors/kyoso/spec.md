## 0. 座標の決め方（ゲームの外形との対応）

- **原点**: `entrance_kyoso`（ワールド (69.60, −64.00)、yaw −155.45）の真下の床。+Y が奥、Z が上。入口の扉は X = 0（REPO）。
- **屋内の外形**（spec.py、共有）: X = −99.07〜+31.08、Y = 4.0（入口面）〜14.5（奥の面）。壁の内側は X = −98.76〜30.78、Y = 4.3〜14.2。奥行き 10.5 m は共有の `_uvbb_for("kyoso")` で決まっていて、棟の担当は変えられない（REPO）。
- **campus.json の輪郭**（ローカルに直したもの）: (31.08, 13.21) → (−88.98, 13.21) → (−88.97, 14.48) → (−99.06, 14.50) → (−99.06, 7.81) → (31.07, 7.72)。長さ約 130 m、奥行き 5.5〜6.8 m、約 722 m²（REPO）。屋内の入口面 Y = 4.0 は輪郭より 3.7 m 手前、奥の面 Y = 14.5 は輪郭より 1.3 m 奥。屋内は Unity で x ≥ 1200 m に離して置くので、この差は見えない。外形はそのまま使う。
- **向き**: 入口面（Y が小さい側）＝キャンパスモール側、奥（+Y）＝葛飾にいじゅくみらい公園側。根拠: PRT114 の断面ダイアグラムは左にキャンパスモール、右に公園を描き、1F へ両側から人の流れの矢印が入る。TUSLIFE のキャンパスマップでも共創棟は公園に面する（確からしさ: 推定。図に方位記号は無い）。
- **実物との大きさの違い**: 実物の建築面積は約 3,516 m²（TOTO、確定）。ゲームの輪郭（約 722 m²）は実物の 1/5 ほどで、細長い帯になっている。実物の 1F は奥行きが深く、ラーニングスクエアの両側にコア・店舗・ラウンジが並ぶ（MAP）。これを奥行き 10 m の帯に**一列に並べ直す**のがこの仕様の方針（推定）。並べる順は、店の位置を外観に合わせて決めた:
  - 外観（`buildings.py build_kyoso`）のスターバックスの看板パネルは X ≒ −12.6〜−3.4、ファミリーマートは X ≒ −44.4 にある（REPO）。屋内でも同じ X に置く。
  - 実物でファミマとスタバは近い（FM `v_fm_07_01` で、ファミマ前の通路の奥にスタバのサイレン看板と木の段床が見える。確定）。
- **作る範囲**: X = −58〜30.78。X = −58 に間仕切りと非常口の誘導灯を置き、その西（X = −98.76〜−58）は閉じる（壁で塞ぎ、閉じた区画の窓側も不透明な壁にする）。
