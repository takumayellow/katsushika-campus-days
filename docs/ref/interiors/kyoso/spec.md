## 0. 座標の決め方

- **原点**: `entrance_kyoso` の真下の床。Z が上（REPO、確定）。
- **軸**: +X を西、−X を東と呼ぶ。Y = 4.0 がキャンパスモール側の外面、Y = 39.734 が公園（葛飾にいじゅくみらい公園）側の外面で、+Y が奥。入口の扉の中心は X = 0、幅 3.2（REPO、確定）。
- **向きの定数**: `FACE_PARK` = 0（+Y を向く）、`FACE_MALL` = π（−Y を向く）、`FACE_EAST` = π/2（−X を向く）、`FACE_WEST` = −π/2（+X を向く）（REPO、確定）。
- **入口**: `blender/kcd_lib/entrances.py` の行 `("kyoso", (7.0, -28.0), (0.0, -1.0), "loop", +1, 3.4, STANDARD)`。扉は長手面の中央からずれているので、屋内の X は扉から東へ 29.874 m、西へ 42.680 m と非対称になる（REPO、確定）。
- **外形**: X = −29.874〜42.680、Y = 4.0〜39.734（72.55 × 35.73 m）。壁 0.30 の内側は X = −29.574〜42.38、Y = 4.3〜39.434。`levels` 11、`height` 45（REPO、確定）。輪郭は航空写真から復元した長方形で ±3〜5 m の幅がある（I281、推定）。
- **spawn / exit**: `spawn_kyoso` (0, 5.8, 0)、`exit_kyoso` (0, 4.55, 0)（REPO、確定）。
- **作る範囲**: 1F の全体（入れない区画は §7）、2F のラウンジとエスカレーターの上の床、吹き抜けから見える 3F のガラスの教室（歩けない）。屋内は Unity でキャンパスから離して置くので、外観と重ならない（REPO、確定）。
- この仕様の座標はすべて建物のローカル座標。
