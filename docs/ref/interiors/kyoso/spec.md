## 0. 座標の決め方（ゲームの外形との対応）

- **原点**: `entrance_kyoso`（ワールド (−9.256, −37.110)、yaw −155.45）の真下の床。+Y が奥、Z が上。入口の扉は X = 0（REPO）。
- **入口**: entrances.py の行 `("kyoso", (7.0, -28.0), (0.0, -1.0), "loop", +1, 3.4, STANDARD)`。キャンパスモール側の長手面に付き、扉は面の中央から 6.4 m ずれた位置にある（REPO）。そのため屋内の X は扉から −X へ 29.874 m、+X へ 42.680 m と非対称になる。
- **屋内の外形**（spec.py が campus.json の footprint の外接矩形から作る）: X = −29.874〜+42.680、Y = 4.0（モール側の外面）〜39.734（公園側の外面）、72.55 × 35.73 m。壁 0.30 の内側は X = −29.574〜42.380、Y = 4.3〜39.434。`levels` 11、`height` 45（REPO）。
- **外形の出どころ**: OSM にも PLATEAU にも共創棟の外形が無いので、campus.json の輪郭は tools/osm_extract.py で手で与えた長方形（約 72 × 35.5 m、長手は第1研究棟と同じ向き）。新しい航空写真 2 種から復元したもので ±3〜5 m の幅がある（I281、推定）。建築面積の公表値は約 3,516 m²（TOTO、確定）で、長方形（約 2,570 m²）との差 約 950 m² は庇・ピロティ・第1研究棟とつなぐ低い部分の可能性がある（I281、未確認）。屋内は長方形の中だけに作る。
- **向き**: Y が小さい側＝キャンパスモール側、+Y＝葛飾にいじゅくみらい公園側。PRT114 の断面ダイアグラムは左にキャンパスモール、右に公園を描き、1F へ両側から人の流れの矢印が入る（確定）。I281 の位置（第1研究棟の北西隣、北東はキャンパスモール、南西は公園）とも合う（確定）。
- **呼び名**: この仕様とコードの「西・東・南・北」は屋内のローカル軸の呼び名で、西 = −X、東 = +X、南 = −Y（モール側）、北 = +Y（公園側）。実際の方位では −X が南東（第1研究棟の側）、+X が北西、+Y が南西に当たる。
- **ブロック**: 西のブロック（西のコア・コンビニ・白い通路）と奥のブロック（ラーニングスクエア・スターバックス・2F ラウンジ）は局所座標で組み、`common.turned` で建物の座標へ動かす（REPO）。
  - 西のブロック: 建物の X = 局所の X + 28.426、Y はそのまま（`at_w`）。局所 X = −58 が西の面の内側 X = −29.574 に来る。
  - 奥のブロック: 建物の (X, Y) = 局所の (X + 25.0, Y + 25.234)（`at_b`）。局所 Y = 4.0 が中ホール側の面（建物の Y = 29.234）、14.5 が公園側の外面（39.734）。
  - この仕様の座標は、ことわりの無い限り建物の座標。
- **作る範囲**: 1F の全体（入れない区画は §7）と、奥のブロックの上の 2F（ラウンジ・前の帯・ブリッジ・バルコニー）、吹き抜けに面した 3F のスラブの縁。屋内は Unity でキャンパスから離して置く（x ≥ 1200 m）ので、外観と重ならない。
