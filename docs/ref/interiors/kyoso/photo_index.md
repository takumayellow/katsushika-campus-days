# 共創棟 写真索引（場所別）

Issue #116 の調査用。写真・図・PDF・動画は scratchpad の `interiors/kyoso/` の下（`img/`、`r1/`、`video/`）にだけ置いてあり、リポジトリには入れていない。

- 場所ごとに分けたのは、調査メモ（`research_visual.md` / `research_official.md`）の説明と、私が写真を見た結果による。1 枚の写真に別の場所が写っていることもある。`s_*.jpg` は同じ画像を縮小したもので、ここには載せない。
- `spec.md` の根拠に使った写真は、Read で開いて確かめてある。
- ライセンスはどの写真も権利者が明示していないので「unknown/copyrighted」とした。写真そのものをゲームやリポジトリに入れてはいけない。
- 食べログの出典は、`in_*` が内観の一覧 /3/、`ext_*` が外観の一覧 /4/、`oth_*` がその他の一覧 /5/。
