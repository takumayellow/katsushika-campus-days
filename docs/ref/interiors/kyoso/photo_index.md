- 場所ごとの分け方は、写真に写っているものによる。1 枚に別の場所が写っていることもある。
- `spec.md` の根拠に使った写真は、開いて中身を確かめてある。
- どの写真も権利者がライセンスを明示していないので、扱いは「unknown/copyrighted」。写真そのものをゲームやリポジトリに入れない。
- 食べログの URL は、/3/ が内観、/4/ が外観、/5/ がその他の一覧。
