# 第2研究棟（食堂 1F・2F と研究室 3〜6F） 写真索引（場所別）

Issue #171、#121。仕様は同じフォルダの `spec.md`。

- 場所は、写真の中の看板・家具・窓の外の景色と、キャプションや記事の本文で分けた。食堂の 1F と 2F は、床の色（1F は赤茶の木、2F は明るいオーク）と椅子（1F は成形合板、2F はシェルチェア）でも見分けられる。
- 「向き・内容」は、この索引のために書いた説明。写真の元の説明文とは違う。略号（YC-S、FM-K1-1 など）は `spec.md` と同じ。
- どの写真もライセンスは不明か、著作物。参考に見るだけにして、ゲームやリポジトリには入れない。ファイル名は、調べたときに scratchpad の `r2/img/` に保存した名前（リポジトリには無い）。`docs/ref/nikken_0#.jpg` だけは前からリポジトリにある。
