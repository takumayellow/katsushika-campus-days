# 第2研究棟（食堂 1F・2F と研究室 3〜6F） 写真索引（場所別）

Issue #121（+#171）。仕様は同じフォルダの `spec.md`。調査日 2026-10-03。

- 場所は、写真の中の看板・家具・窓の外の景色と、キャプションや記事の本文で分けた。食堂の 1F と 2F は、床の色（1F は赤茶の木、2F は明るいオーク）、椅子（1F は成形合板、2F はシェルチェア）、カウンターの帯の色（1F はえんじ、2F はオレンジ）でも見分けられる。本文やキャプションに階が書いてあるものは「確定」、見分けただけのものは「推定」と書く。
- 「向き・内容」は、この索引のために書いた説明。写真の元の説明文とは違う。略号（YC-S、FM-K1-1、TB01、V-KITA など）は `spec.md` と同じ。
- どの写真・動画もライセンスは不明か、著作物。参考に見るだけにして、ゲームやリポジトリには入れない。ファイル名は、調べたときに scratchpad の `interiors/research2/img/` に保存した名前（リポジトリには無い）。動画は YouTube のストーリーボード（320×180 のコマ）を `img/sb/<動画ID>_M*.jpg` に落として見た。`docs/ref/nikken_0#.jpg` だけは前からリポジトリにある。
- 撮影・公開の時期は、記事の日付、写真の中の掲示、写っている設備（2022-10 に入ったタッチ式の券売機、2024 年以降の QR のポスター）から決めた。時期の分からないものは「時期不明」と書く。
