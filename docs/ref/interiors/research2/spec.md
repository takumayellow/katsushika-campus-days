## 0. 座標の決め方（ゲームの外形との対応）

- ローカル座標は DESIGN.md §3.4 のとおり。原点 = `entrance_research2` の真下の床、+Y = 奥、Z = 上。ワールドへの変換は x = 6.0634 + 0.9096·X + 0.4156·Y、z = −21.6235 − 0.4156·X + 0.9096·Y（入口の yaw 24.5514°）。確からしさ: 高（REPO の計算値）。
- **外形**（REPO、campus.json buildings[2] の 15 点。HEAD ローカル）: (−39.68, 41.26) (−40.71, 44.12) (−45.57, 44.33) (−46.38, 32.65) (−49.45, 32.52) (−46.15, 25.23) (−40.75, 16.90) (−31.50, 8.49) (−20.20, 4.00) (−18.69, 7.69) (−8.45, 5.54) (8.36, 6.22) (9.13, 19.11) (31.88, 19.18) (31.78, 41.35)。面積 2,327 m²、外接矩形 81.3 × 40.3 m（X −49.45〜+31.877、Y 4.0〜44.327）の 71 %。壁厚 0.3 m。
  - 南南西の面は X −8.45〜+8.36 で Y 5.54〜6.22（扉のある面）。その東の段の面は X 8.4〜9.1（Y 6.2〜19.1）。東の部分（研究棟側）の南南西の面は Y 19.1。切り欠きは X −20.2〜−18.7（外階段の所）。西北西は折れ線の曲面。
  - 外接矩形のうち輪郭の外の約 950 m²（段の面の前の広場 X 9〜31.9・Y 4〜19.1、西北西の角、切り欠き）は近景からも切り取られる。窓の外に見える地面・舗装（レンガ敷き）は plan で補う。
- **扉**: `entrances.py` の `("research2", (14.5,-22.0), (0.0,1.0), "loop", +1, 3.4, STANDARD)`（注記「南面の直線部（u 6..23）の中央。食堂の前」）。STANDARD は幅 3.2 m（半幅 1.6）・高さ 2.6 m・風除室の奥行き 2 m。実際の扉はローカル **(0, 5.879)**、ワールド (8.506, −16.276)、扉の外向き法線 (−0.379, −0.926)（南南西）。風除室は Y 5.88〜7.88。検査は DOOR_DOT_MAX −0.9・DOOR_LATERAL_TOL 0.05、原点が扉の外。確からしさ: 高（REPO）。
- **実物の入口との関係**: 食堂の入口は、スラブの張り出しが始まる所の 1F のガラスの風除室（YC-S、FM-K1-1、TT01。高）。旧 spec の候補 A は HEAD (7.4, 10.3)、東南東向き（段の面）で、ワールド (17.1, −15.3)。今の扉（南南西の面の X 0）とは面が違う。扉を A へ動かすには DOORS と `spec.py` の原点の決め方を変える必要があり、plan だけでは動かせない（door_mismatch）。この仕様は**今の扉の位置**で 1F の入口ホールを作り、A への移設は §12 に挙げる。
- **旧 spec からの換算**: 旧 spec（dev/game の sidecar 基準。外形 X ±40.663、入口ワールド (−1.9285, −17.9728)）の X は **HEAD X = 旧 X − 8.787**、Y はそのまま。旧 spec のワールドの点はそのまま使える。
- **向き**: OC24 の略図の注記は「図書館側 West」「East 正面入口側」。campus.json の配置ではローカル −X が図書館（西北西）、+X が東南東。したがって **OC24 の West = ローカル −X、East = +X**。OC24 の縮尺は 589 px = 71.5 m（0.1214 m/px）で、HEAD X = (px − 168) × 0.1214 − 39.64。確からしさ: 中。
- **スラブ（3〜6F）の範囲**: X −39.64〜+31.86、Y 15.4〜41.3（71.5 × 25.9 m）。南南西は Y 19.1 の面から 3.7 m（YC-S、TL-08）、基壇からは約 9 m 張り出す。確からしさ: 中（OC24 + AIR）。
