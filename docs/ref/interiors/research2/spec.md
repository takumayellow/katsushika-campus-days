## 0. 座標の決め方（ゲームの外形との対応）

- **ゲーム座標**: 原点は緯度 35.771909746153845、経度 139.86296726153847。x = 東、z = 北（m）。緯度 1° = 110,954.786 m、経度 1° = 90,422.693 m で換算した。
- **室内の外形**（`research2.json`）: X = −40.663〜+40.663、Y = 4.0（入口の面）〜44.327（奥の面）。OSM の輪郭の外接矩形とほぼ一致する。入口の Empty はワールド (−1.9285, −17.9728)、yaw 24.5514°。**+X = 東南東、+Y = 北北東（建物の奥）**。
- **換算**（入口の Empty の位置と向きから）: x = −1.9285 + 0.9096·X + 0.4156·Y、z = −17.9728 − 0.4156·X + 0.9096·Y。以下の「ワールド」はこの式の値。
- **輪郭**（OSM、確か）: 面積 2,327 m²。北北東の辺は一直線（Y = 41.3、X −30.85〜+40.65）で、その向きは −24.5°（`campus.json` のキャンパスの向き −24.55° とそろう）。
