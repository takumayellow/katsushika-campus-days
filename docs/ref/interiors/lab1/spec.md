## 2. 実物の事実

- 4 階建て、高さ 17.0 m（OSM、確定）。
- 1F: 機械工作工場1・機械工学科の研究室 2 室・NMR（WIKI、確定）。2F: 建築学科実験室・機械工作工場2。3F: トライボロジーセンター・生物環境イノベーション研究部門・飯田研究室。4F: RI 実験室・スペースシステム創造研究センター（WIKI、確定）。
- ゲームの屋内は 1F だけを作る。上の階は階段・EV の案内板で示す（推定）。
- 機械工作工場の中（TUSLIFE katsushika_04、確定。写真で直接見えたもの）:
  - 緑のエポキシ樹脂の床、白い壁、天井は仕上げの無い躯体で、ダクト・ケーブルラック・蛍光灯・天井カセット形のエアコンが露出。
  - 青いフライス盤、卓上ボール盤、ワイヤ放電加工機、平面研削盤、オレンジ色の天板の作業台と万力、壁掛け時計、木々が見える窓。
- 床の高さの安全表示（黄色の通路線）は工場の一般的な仕上げとして置いた（推定。写真では確認できていない）。
