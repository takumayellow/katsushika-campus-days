# 第2実験棟（大型実験ホール）作り直し仕様

Issue #118。調査日 2026-10-13。第1実験棟の仕様（`../lab1/spec.md`）と対にして読む。

確からしさ: **確定** = 公式の文・OSM の数値。**推定** = 他大学の同種の実験棟の一般的な作りと、公式の 1 文からの見積もり。**不明** = 資料が無いもの。

## 1. 分かっていること

- 公式の説明: 「各学科から求められる特殊な要件に応える実験施設」（確定）。
- OSM: 2 階建て、高さ 9.0 m（確定）。外形は奥行き約 23.7 m、間口約 15.8 m で、第1実験棟（4 階建て 17 m）より小さい（REPO）。
- **不明**: 内部の写真、室の構成、入っている学科。公開資料は見つからなかった。

## 2. 方針（推定）

「各学科の特殊な要件」を、天井の高い実験ホールとして表す。9 m の 2 階建ての外形に収まる最大の特別な空間は、1〜2F をぶち抜いた大空間である。建築・土木系の構造実験棟に共通する要素を置く（すべて推定）:

- 高さ約 7 m の吹き抜けと天井クレーン（走行桁・ホイスト・吊り具）。
- アンカー穴を格子状に開けた強固な床と、反力壁・反力フレーム。
- 供試体（コンクリート梁・柱）、載荷試験の治具、振動台。
- 計測制御室（ガラス越しにホールが見える）と準備室。

第1実験棟は「小さな部屋が並ぶ廊下型」、第2実験棟は「ひとつの大空間」とすることで、2 棟の違いを出す。

ローカル座標: 屋内は X = −5.96〜+9.26、Y = 3.3〜26.43。入口は DOORS から導かれ、短辺の X = 0 付近。
