# 航空写真（地面と面の色の参考）

Issue #59 / #78 で地面・舗装・芝・水盤などの色とテクスチャを決めるときに見た、国土地理院のオルソ画像です。

## 出典

- 出典：国土地理院 電子国土基本図（オルソ画像）を加工して作成
- `aerial_campus_z18_osm.jpg` に重ねた建物・道・区域の線：© OpenStreetMap contributors（[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)、https://www.openstreetmap.org/copyright）

使ったタイル（ort）は[地理院タイル一覧](https://maps.gsi.go.jp/development/ichiran.html)の「2. 基本測量成果以外で出典の記載のみで利用可能なもの」に載っていて、
[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)に従い、出典と加工したことを書けば申請なしで使えます（2026-09-24 確認）。
つなぎ合わせ・切り出し・拡大縮小・回転・注記の追加をしているので「加工して作成」と書いています。

## 色の見本

各面の矩形の画素を、sRGB のままチャンネルごとに中央値をとった値です（横断歩道だけ 90 パーセンタイル）。
矩形の位置は `aerial_crops.json` の `rect`（切り出し画像の画素、右下は含まない）にあります。

補正値は推定で、測った値ではありません。

- 白補正：体育館の白い屋根を無彩色とみなし、チャンネルごとの倍率で青緑かぶりを消した値
- かすみ除去＋白補正：モザイク全体の 0.1 パーセンタイル（55, 72, 73）を差し引いてから白補正した値。暗い面や影では補正が効きすぎる

図書館の平屋根 #D5DAD8、正門広場の影の部分 #808F96（いずれも生の値）。

オルソ画像の色には、かすみと青緑のかぶり（無彩色の屋根で B−R が約 +6、車道で約 +13）が乗っています。
そのため値はそのまま写さず、面どうしの明るさと色みを比べる根拠として使いました。

ほかに、写真から言えないこと：

- 解像度は 0.4845 m/px なので、約 1 m より細かい舗装の目地や模様の寸法は読めない
- 高い建物の屋根は倒れ込んで写るので、OSM の外形からずれる。屋根の見本は写真を見て置いた
- 太陽が南にあるため、共創棟などの影がモール東側と正門広場の一部に落ちている
