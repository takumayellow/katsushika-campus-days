# 体育館 外観

Issue #240。調査日 2026-10-13。資料の画像はリポジトリに入れない（大学・撮影者の著作物）。ここには URL と読み取った内容だけを書く。`docs/ref/katsushika_map.png` は前からリポジトリにある公式マップと同じ画像。屋内の資料は `docs/ref/interiors/gym/`（`spec.md`・`photo_index.md`）。

確からしさ: **高** = 公式資料・計測データ・空中写真をそのまま読んだもの。**中** = 縮尺の無い絵や斜めの写真から推定したもの。**低** = 写真が無く、ゲームの都合で決めたもの。

## ゲームでの作り

`blender/kcd_lib/gym_exterior.py`（`buildings.build_gym` から呼ぶ）。

| 項目 | 決めたこと | 確からしさ |
|---|---|---|
| 塊の分け方 | 輪郭の辺を、両端の u が 7.1 以下ならアリーナ、それ以外は部室の棟 | 中 |
| アリーナの壁 | 0〜(h−5.4) m を明るい壁、最上部にハイサイドライト 2 段。西・南の最長の辺は 1 階に連続窓（窓台 0.9 m）、1 階の上〜4 階に白い縦フィン（間隔 1.2 m・出 0.40 m） | 中 |
| 部室の棟の壁 | 東の最長の辺は `_lab1_stair_slot`（レンガ + 外階段）、北の最長の辺はレンガ。南・西の最長の辺は 2〜6 階に連続窓 + 水平ルーバー（南は 1 段、西は 2 段 / 階）、1 階は南が大きな窓、西が壁。ほかの辺は 1 階が壁、2 階から上は明るい壁 | 中 |
| 庇 | アリーナの南の最長の辺に、2 階の床の高さで出 2.0 m。入口の前（±3.8 m）は空ける | 低 |
| 屋根 | アリーナ = `metal_white`、北の帯 = `roof_grey` の重ね板 + 箱 2 + 室外機 2 × 5、部室の棟 = `grass` の重ね板 + 空調機 2 + 排気筒 3。パラペット 0.9 m（レンガの面はレンガ色） | 中（配置は AIR、寸法は推定） |
| 当たり判定 | 地面の高さの輪郭は OSM の輪郭のまま。張り出し（フィン・庇・踊り場・ルーバー）は 2 階の床より上だけ。ミニマップの形は `campus.json` の輪郭なので変わらない | — |
| 北の別棟 | 作らない（旧: 輪郭の北へ 9 m 出ていた 16.5 m の箱） | 高 |
| 看板 | 店名・人名は出さない | — |
