# 構内の写真（色の参考）

Issue #59 / #78 で煉瓦・舗装・芝・水・土の色を決めるときに見た、葛飾キャンパスとにいじゅくみらい公園を地上から撮った写真です。
すべて Wikimedia Commons で自由なライセンスで公開されているもので、ライセンスはファイルごとに違います。ゲームには入っていません。

上から見た色は [`../aerial/`](../aerial/README.md)（国土地理院の航空写真）にあります。こちらは壁の煉瓦・敷石の目地・季節ごとの芝のように、真上からは見えないものの参考です。

## 色の見本

矩形の画素を、sRGB のままチャンネルごとに中央値をとった値です（補正はしていません）。
矩形の位置は `samples.json` の `rect`（このフォルダの画像の画素 [x0, y0, x1, y1)、右下は含まない）にあります。

地上の写真なので、同じ面でも日なたと日陰・曇りと晴れ・季節で大きく変わります。値はそのまま写さず、面どうしの色みと明るさを比べる根拠として使いました。
「全体」と書いた見本は、格子・窓・影をまとめた平均的な見え方です。
