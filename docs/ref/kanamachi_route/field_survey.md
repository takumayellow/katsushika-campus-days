# 金町駅から葛飾キャンパス入口までの現地記録（#443）

大学の[通学路図](https://www.tus.ac.jp/tuslife/campus/katsushika/schoolroutemap.pdf)で赤い点線の経路を確認し、JR 金町駅北口の**駅舎の外**からキャンパス入口まで歩いて記録する。訪問日と、通学路図の版をメモする。地図にある別経路は今回は撮影対象に含めず、混同しない。

## 持ち帰る記録

| 記録 | 撮る場所・書く内容 | 実装で使うこと |
| --- | --- | --- |
| 出発点 | 北口の外から、駅出口と進行方向が同時に分かる写真。駅構内図の北口との対応をメモする | プレイヤーの開始位置と向き |
| 通学路図の各折れ点 | 曲がる手前・曲がった直後を進行方向に各 1 枚。前後の折れ点が分かるように番号を振る | 道の折れ線の順序 |
| 横断箇所・信号 | 横断歩道の両端、信号、歩道の接続を写す。どちら側の歩道を通ったかを記録する | 安全な歩行面と当たり判定 |
| 理科大大学通り | 通学路図と照らして進行方向・逆方向の景色を撮る。舗装、植栽、柵、街灯の繰り返しが変わる所を記録する | 道の幅と沿道の再現 |
| 到着点 | キャンパス入口の外・内側から、歩道とキャンパス内の既存シーンにつながる位置を撮る | 駅ルートと既存キャンパスの接続 |
| 連続動画 | 北口外から到着点まで、曲がり角・横断箇所で一度止めて左右を写し、地図の番号を声やメモで残す | 写真の位置と順序の照合 |

写真・動画を共有する前に、人の顔、車のナンバー、個人情報が読める掲示物が残っていないか確認する。顔が写った場合は、顔が分からないよう処理した版を使う。

## 記録表

各地点を K00（北口外）、K01 以降（折れ点・横断箇所）、最後を KC（キャンパス入口）として、次を一行ずつ書く。位置情報を持つ写真なら緯度経度を残す。GPS が大きくずれた点は「位置要確認」と書く。

| ID | 通学路図の位置・目印 | 緯度・経度または要確認 | 撮影ファイル名 | 進行方向 | 歩道側 | 信号・段差・障害物 | 要確認 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| K00 | 金町駅北口外 | 要確認 |  |  |  |  |  |

## 実装へ渡す前の照合

1. 大学の赤い点線と記録した K00 → KC の順序が一致するか確認する。地図で読めない曲がり方は推測で補わない。
2. 緯度経度を tools/osm_common.py の原点・投影で x/z に変換し、既存 campus.json の境界と照合する。駅ルートの元データは #41 の寮ルートと分けて保存する。
3. WorldBounds の壁、寮ルートの西門、ミニマップ、プレイヤー開始位置に与える影響を確認してからモデルを生成する。
4. 形・素材・通行可否を確認できなかった場所は、Issue と PR に「要確認」を残す。
