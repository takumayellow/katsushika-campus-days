# 煉瓦の色の実測（ratio 法, #109）

方法: sRGB を線形に戻し, 煉瓦の矩形の中央値を同じ写真の灰の基準面の中央値でチャンネルごとに割り, concrete_grey #B4B2AC（線形）を掛けた。基準面は白飛び（どれかのチャンネル >= 250）の画素を除き, 輝度の下 20% と上 5% を落とした中央値。基準面の 3 割超が白飛びの写真は重みを 0.3 倍。目地は「彩度 < 0.16 かつ明度が矩形の中央値の 1.15 倍超」で除いた。写真のトーンカーブは線形でないので, 補正後の値にはその分の誤差が残る。

矩形は元画像の画素 [x0,y0,x1,y1)。赤=煉瓦, 水色=基準面（measure_ratio_rects.jpg）。

## 合成値

- 重み付き平均（線形, 目地を除く）: **#634E42** Lab [35.0, 6.9, 10.5]
- 重み付き中央値: #5F4B3F Lab [33.6, 6.5, 10.4] / 目地込み平均: #654E43
- 写真ごとの L* の範囲（重み0 も含む）: [28.2, 35.0, 66.0]
- 目地（検出できた写真の重み付き平均）: #8D8581。遠景では目地は解像しておらず, 暗い煉瓦との混同もあり得るので参考値。

## 除外・注意

- nikken_02: 補正後が無彩色の暗い灰。煉瓦の面が日陰で空の青を受けているとみられ, 除外。
- flickr_brick_wall_concrete_sunny: 基準の打ち放しが #99816F と暖色に, 煉瓦が紫に寄った。逆光とフレアで色が崩れているとみて除外。
- 白いパネル（石張りの塔）を基準にした写真は重み 0.3 以下。白いパネルは打ち放しより明るいはずなので, その写真の補正後は暗めに出る向き。ただし実測では打ち放し基準の写真と同じ範囲（L* 32〜37）に入った。
- 測れた写真は講義棟の校名サイン壁に偏っている（重みの大半）。研究棟の端部・共創棟・図書館は未測定か重みが低い。
- 未着手: 共創棟（prtimes）, 図書館（christinayan）, homemate の近接写真, 高所からの全景写真（tus_en_hero, nikken_top）。
