# 葛飾キャンパスデイズ 遊び方

東京理科大学 葛飾キャンパスを歩き回り、学生たちと話し、1 日を過ごす三人称探索ゲームです。

## 起動

ブラウザ版: https://takumayellow.github.io/katsushika-campus-days/ を開くだけ（Chrome / Edge / Firefox、WebGL 2）。
セーブはブラウザ内に保存されるので、ブラウザのサイトデータを消すと消える。
ゲーム中はマウスカーソルが画面に取られる。Esc でカーソルが戻り、画面をクリックするとまた取られる。Ctrl+F で全画面とページ内表示を切り替える。

Windows 版:

1. zip を右クリックして「すべて展開」し、`KatsushikaCampusDays/KatsushikaCampusDays.exe` を起動する（zip の中から直接は起動しない）。
2. 初めて起動するとき「Windows によって PC が保護されました」と出ることがある（exe に署名をしていないため）。「詳細情報」を選ぶと出る「実行」を押すと起動する。
3. Windows 10/11 64bit、DirectX 11 対応 GPU。インストールは不要。
4. セーブデータは `%USERPROFILE%\AppData\LocalLow\KCD\Katsushika Campus Days\kcd_save.json` に 1 枠。見たエンドの記録は同じフォルダの `kcd_endings.json` にあり、「はじめから」でも消えない。

## タイトル画面

- 回転台の 3 人から主人公を選ぶ: **みらい**（理科大生）、**坊っちゃん**、**マドンナちゃん**。
- 「はじめから」で朝 8:30 のキャンパスから開始。「つづきから」でセーブを読む。
- C でクレジット、O で設定を開く（ゲームパッドは Y でクレジット、View で設定）。
- 主人公は ← → か A / D で選び、Enter で決める（ゲームパッドは十字キーの左右と A）。
- 「クレジット」に地図データ（OpenStreetMap, ODbL）などの帰属表示がある。地図データの帰属はタイトル画面の右下にも出ている。

### スマートフォン・タブレット（ブラウザ版）

画面に触れると、指で遊ぶための操作が出る（#187）。縦持ちでも横持ちでも遊べる。
キーボードかマウスを使うと、PC の操作に戻る。

| 操作 | 指 |
| --- | --- |
| 移動 | 画面の左側に指を置いて、その位置から倒す |
| 視点 | 何もない所を 1 本指でなぞる |
| ズーム | 2 本指で広げる・つまむ |
| 走る | 「走る」を叩く（止まると歩きに戻る） |
| ジャンプ | 「ジャンプ」 |
| 話す / 調べる / 入る / 座る | 「話す 調べる」 |
| クエストログ | 上の「クエスト」 |
| ポーズ・設定・セーブ | 上の真ん中の「II」 |

- 会話の選択肢・ポーズ・設定は、行を叩いて選ぶ。設定の値は ◀ ▶ を叩いて変える。

## 1 日の流れ

- ゲーム内時間は朝 8:30 から進み、昼・夕方・夜で空と BGM、歩いている学生たちが変わる。
- 建物の入口に近づくと名前が出る。E で中に入ると、講義室・食堂・図書館・体育館・研究室・実験室・温室などの内部を歩ける。
- NPC（いなり・かなめ・そら・教授）に話しかけるとメインクエスト 7 本とサブクエスト 6 本が進む。
- キャンパスには隠しアイテム 23 個と写真スポット 6 か所がある。集めると称号が増える。
- 夜になると 1 日の終わりのリザルト画面が出て、達成度で S / A / B / C 評価が付く。

## フォトモード

P（ゲームパッドは Y）で入る。画面の表示が消えて時間が止まり、カメラだけを動かせる。P か Esc（ゲームパッドは Y か B）で元の画面に戻る。

| 操作 | キーボード / マウス | ゲームパッド |
| --- | --- | --- |
| カメラの移動 | W A S D / 矢印キー | 左スティック |
| カメラの上下 | E で上、Q で下 | RT で上、LT で下 |
| 向き | マウス移動 | 右スティック |
| ズーム | マウスホイール | 十字キーの上下 |
| 速く動かす | Shift（押しっぱなし） | LB（押しっぱなし） |
| 撮る | Enter / Space | A / X |
| 入ったときの位置に戻す | R | 右スティック押し込み |
| 操作案内を消す / 出す | H | 左スティック押し込み |
| 戻る | P / Esc | Y / B |

- カメラは主人公から 8 m 以内で動かせる。壁・床・天井・木の幹は通り抜けない。
- 撮った写真は Windows 版では `%USERPROFILE%\AppData\LocalLow\KCD\Katsushika Campus Days\Photos` に PNG で保存される。

## 開発者用のワープメニュー

確かめたい場所へすぐ行くためのメニュー。Unity のエディタと Development Build では最初から使える。
ブラウザ版では、アドレスの末尾に `?dev=1` を付けて開いたときだけ使える（例 `http://127.0.0.1:8765/?dev=1`）。
付けなければ何も出ず、キーも効かない。使えるときは画面の右上に赤い「DEV」が出る。

- F2 で開く。開いている間は時間が止まる。もう一度 F2 か Esc で閉じる。
- ↑ ↓ で行を選び、← → で見出し（場所 / 建物の中 / 人 / 時刻）を切り替え、Enter で移動する。
- 行き先はシーンのデータから作る。場所はキャンパスの訪問ゾーンと各棟の入口前、建物の中は入れる建物すべて、
  人は話しかけられる NPC の前、時刻は朝・昼・夕・夜。
- 建物の中にいるときに屋外を選ぶと、先に外へ出てから移動する。
- キャンパスにいて、会話・ポーズ・写真モード・リザルトなどが出ていないときだけ開ける。

## うまく動かないとき

- 起動する前に Windows に止められる: Smart App Control が有効な PC では、署名のないアプリが止められることがあり、個別に許可する方法が無い。その PC ではブラウザ版で遊ぶ。
- 画面が真っ暗、または起動しない: `KatsushikaCampusDays.exe -force-d3d12` で起動して DirectX 12 に切り替える（既定は DirectX 11）。
- ログ: `%USERPROFILE%\AppData\LocalLow\KCD\Katsushika Campus Days\Player.log`
